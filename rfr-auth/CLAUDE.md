## Неочевидное

- Регистрация пишет только в `rangiffler-auth`. Профиль API появляется при первом `Query.user`.
- `POST /register` требует CSRF той же сессии: сначала `GET /register`. Успех — 201, ошибка валидации или занятый username — 400.
- `GET /login` без сохранённого OAuth-запроса уводит на фронтенд. Вход начинается с `/oauth2/authorize` или кнопки Login.
- RSA-ключ подписи генерируется при каждом старте: после перезапуска выданные токены невалидны.
- OAuth-авторизации и сессии живут в памяти и пропадают при перезапуске.
- Публичный клиент `client` без секрета, refresh token не выдаётся.
