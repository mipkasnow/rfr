# Тестовые данные

- Имя и пароль уникальны: `TestUser.unique()`. Чужие строки не переиспользовать.
- Владелец данных — дерево `UserFixture`. Тест получает `TestUser` и в БД не пишет.
- Новая связь — новое значение `Relation`. Другое предусловие — новый декоратор вокруг `origin`. Подключает `UserRequest.fixture()`, не `UserExtension`.
- SQL только в объектах строк `data/db` и файлах `sql/`. В фикстуре, extension и тесте запросов нет.
- Профиль API создаётся явно (`ApiProfile.create()`), не первым заходом в приложение.
- Пул заранее заведённых пользователей — только если создать пользователя в тесте нельзя. Такой пул не удаляет строки из БД.
