## Что настоящее, а что мок

| Возможность | Реализация |
|---|---|
| Профиль (`Query.user`, `Mutation.user`), страны, люди, дружба | БД `rangiffler-api` |
| Лента и статистика (`Query.feed`) | JSON из `src/main/resources/mock/`, одинаковый для всех |
| Создание, редактирование, лайк и удаление фото | Мок: ответ корректный, но ничего не сохраняется |

Таблицы `photo`, `like`, `photo_like`, `statistic` есть в миграции, но приложение их не использует. Моки не заменять, пока об этом не попросят.

## Неочевидное

- Профиль создаётся при первом `Query.user` со страной `ru`.
- Пользователи API и auth связаны только по username, UUID разные.
- Ошибки GraphQL приходят с HTTP 200; тип — `extensions.classification`.
- Принимается только access token. Query требует `read`, mutation — `write`.
- Дружба — одна строка на пару. `ADD` создаёт `PENDING`, `ACCEPT` и `REJECT` доступны только адресату, `DELETE` — любой стороне.
- Каскадных внешних ключей нет: перед удалением пользователя удаляются его строки `friendship`.
- Java-модель схемы генерирует DGS Codegen, руками её не пишут.
